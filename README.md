# 🛡️ PhishGuard – Phishing Awareness Training

## 📌 Project Overview

PhishGuard is an interactive web-based phishing awareness training module developed as part of the CodeAlpha Cybersecurity Internship.

The project helps users understand phishing attacks, recognize suspicious emails and fake websites, identify social engineering techniques, and follow safe cybersecurity practices.

It also includes real-world phishing examples and an interactive quiz to test the user's knowledge.

---

## 🎯 Objectives

- Understand what phishing is.
- Learn how phishing emails work.
- Identify fake and suspicious websites.
- Recognize common social engineering techniques.
- Learn how to protect personal and sensitive information.
- Practice identifying phishing attempts through examples.
- Test cybersecurity awareness through an interactive quiz.

## 🧠 Topics Covered

### 1. What is Phishing?

Phishing is a cyberattack where attackers use fake emails, messages, websites, or other communication methods to trick users into revealing sensitive information.

### 2. Social Engineering

The project explains common psychological techniques used by attackers, including:

- Urgency
- Fear
- False authority
- Rewards and offers

### 3. Phishing Red Flags

Users learn to look for warning signs such as:

- Unknown or suspicious senders
- Unusual website URLs
- Urgent requests
- Requests for passwords or OTPs
- Unexpected attachments
- Suspicious links

### 4. Fake Websites

The project demonstrates how fake websites can imitate legitimate services and explains why users should verify website addresses before entering sensitive information.

### 5. Protection Practices

Users are encouraged to:

- Use Multi-Factor Authentication (MFA)
- Use strong and unique passwords
- Verify suspicious requests independently
- Avoid clicking unknown links
- Never share OTPs or passwords
- Report suspicious messages
